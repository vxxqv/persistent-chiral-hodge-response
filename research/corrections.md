# Development corrections retained

1. The planning pilot used a symmetric scalar test weight on index-oriented triangles. A source is alternating under relabelling, so that readout is not permutation invariant. The current readout uses an alternating, reflection-even probe; the scalar is their inner product.
2. The initial exhaustive-topology test contained an unverified expected nested-pair count of 3,461. Actual enumeration visited 3,046 pairs and all operator/rank comparisons passed. An independent count by edge subsets and optional supported triangles also gives 3,046. The expected count was corrected; the mathematical domain and enumeration were unchanged.

The final results and manuscript must use the corrected construction and actual tested domain. These corrections do not turn numerical checks into proofs or confer independent-review status.
