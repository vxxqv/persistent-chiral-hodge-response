# Persistent Chiral Hodge Response

Research software, selected source data and generated molecular geometries for persistent chiral Hodge responses, conformer-law geometry and constrained molecular motion. Version 1.0.0.

Author: Vivaan Patni (GitHub: vxxqv).

Version 1.0.0: [DOI 10.5281/zenodo.23770661](https://doi.org/10.5281/zenodo.23770661). Zenodo version family: [DOI 10.5281/zenodo.23741544](https://doi.org/10.5281/zenodo.23741544). The historical [v0.2.0 archive](https://doi.org/10.5281/zenodo.23741545) and Git tag remain immutable. Package versions, protocol hashes and replay records distinguish the newer analyses from that earlier release.

## Scope

The software computes a reflection-odd triangle cochain, the real persistent Laplacian with its inherited inner product, signed readouts, proper-rigid shape derivatives, odd Gaussian kernel means and covariance-resolvent scores. The extension includes 512 external parents / 5,514 source conformers, and a separately curated biological cohort of 143 same-assay binding comparisons / 103 parents / 65 human targets, with 1,648 generated conformers. Generated geometries are not experimental structures or equilibrium trajectories. Measured ChEMBL binding records are archived separately with their assay and target identities.

Version 1 adds distance-constraint stress obstructions, exact rooted-bridge torsion charts, quotient metrics and intrinsic Hessians on 206 biological isomers; periodic energy sublevels and reduced conformer measures; mass-horizontal velocity fields, connection curvature and zero-angular-momentum reconstruction; reduced Hamiltonian paths and an independently organized forced-geodesic check; effective two-coordinate quantum operators using exact Fourier integrals of explicit bilinear coefficients; exact Temperley-Lieb/Jones fixtures and a unitary braid representation; and closure-dependent Fox determinants for experimental PDB chains 1J85 A, 2EFV A and 1UBQ A. A protein closure determinant is neither a complete knot classifier nor an intrinsic invariant of an open chain. The quantum operator is a declared reduced model with an empirical potential, not an electronic calculation or a validated thermochemical method.

Manuscript sources, manuscript PDFs, plans, and submission materials are deliberately outside this repository and its archival package.

## Reproduction

Use Python 3.12. Install with `python -m pip install -e .[test,figures,external]`, then run `python -m pytest`. Exact executed package versions are in `environment_versions.json` and `requirements-lock.txt`. Set `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1` and `MKL_NUM_THREADS=1` before multiprocessing. The executed environment is Windows; figure text uses Arial, and 3D rendering additionally requires working VTK/OpenGL.

- Original pilot: `python -m pchr.experiment --output replay/pilot`; coordinates are in `data/conformers.json`. `python -m pchr.generate_data` regenerates the source panel. `python -m pchr.geometry_experiment` reproduces its shape derivatives.
- Full external descriptor replay: `python scripts/replay_extension.py --output replay/external --recompute-descriptors --workers 4`. This recomputes every selected descriptor from archived coordinates, compares all component values and separation metrics, and reproduces the paired bootstrap. Omitting `--recompute-descriptors` checks scores from stored features only. The original full parquet and full embedding arrays are not needed.
- Parity diagnostic and calculus: copy `results/external_full` to a separate replay folder, then run `python -m pchr.ensemble_diagnostics replay/external_full`, `python -m pchr.ensemble_geometry replay/external_full` and `python -m pchr.kernel_shape_metric replay/external_full`.
- Biological curation: `python -m pchr.biology --raw data/extension_sources/chiral_cliffs --output replay/biology`. Compare its same-assay rows with `results/biology_cliffs`. The small 3DCS-linked acquisition uses the separate `data/extension_sources/3dcs` snapshot and `results/biology_linked`; it does not supply the main biological estimate.
- Biological generation and association: `python -m pchr.biology_ensembles replay/biology --workers 4`. This regenerates deterministic ETKDGv3/MMFF94s conformers when its `ensembles` cache is absent. Copy the archived `results/biology_cliffs/ensembles` there to reproduce associations from exactly the stored rounded geometries instead. Eight generated conformers per isomer have uniform descriptive weights; stored optimization energies belong to pre-rounding coordinates.
- Complete constrained-conformer replay: `python scripts/replay_constrained.py replay/constrained --workers 4`. It recomputes all 206 first-conformer derivatives and both 33/65 grids, comparing 214 JSON records and 40 array entries against the archive. Use a new replay folder to avoid cache reuse.
- Complete quantum, field and protein replay: `python scripts/replay_quantum_kinematics.py replay/quantum --workers 2`. It requires a new empty output directory and recomputes 6 coefficient models / 36 eigenproblems, 4 reduced trajectory integrations, 2 curvature grids, 8 holonomy loops, 192 protein closures and 576 additional projections. It compares finite spectra, densities, geometric arrays and saved summaries. Eigenvector phases are arbitrary and are aligned in that comparison. Molecular results are regenerated from archived conformers and raw PDB files, not from figure screenshots.
- Additional validations are executable separately with `python scripts/validate_molecular_flow.py --output replay/flow_check` and `python scripts/validate_protein_topology.py --output results/protein_knots`. The latter operates on a folder containing the three already computed protein records; use a copy for a separate replay.

The redesigned figures use `python figures/rebuild.py --output figure_exports --cache figure_cache`, then `python figures/extension.py --output figure_exports --cache figure_cache`. The new figures use `python figures/constrained.py figure_exports --cache figure_cache` and `python figures/quantum_kinematics.py figure_exports --cache figure_cache`. They export PNG/PDF/SVG, captions, camera metadata and source data. Run `python figures/check_source.py figure_exports` and `python figures/check_extension_source.py figure_exports` for numerical source checks. Source records for all 26 figure sets are archived in `results/figure_source`; manifests in `results/figure_manifests` preserve cameras, dimensions and text bounds. Export inspection uses `python figures/audit.py --figures figure_exports --qa figure_qa`; its manifest covers the original figure family, while the two new generator manifests are also retained. The exact font is `C:/Windows/Fonts/arial.ttf`; a different platform must record an explicit font substitution. The earlier `pchr.figures` module is retained for historical reproduction.

## Mathematical conventions

All chain spaces are real, ordered simplices have the increasing vertex orientation, simplex bases are orthonormal, and degree-two complexes are constructed through dimension three. Rips radius is the maximum edge distance in angstroms. Source bandwidth is distinct from filtration radius. Persistent restricted-boundary null spaces use orthonormal columns. All test set sizes, tolerances, and numerical ranks are reported with their output records.

## Status

The frozen protocol, outcome-blind structural selection, acquisition amendments and post-primary diagnostic status are retained. The primary external persistent-minus-source ES-AUC difference is -0.0425003, parent bootstrap 95% interval [-0.0523411,-0.0325988]. The primary biological Spearman correlation is 0.0498867 [-0.1536638,0.2462794]. These results establish no general benefit for propagation. No parameter or endpoint was replaced with a favourable result.

The constrained cohort has full numerical torsional response rank in 204/206 cases at the three reported tolerances; this is not an exact rank theorem. Energy sublevel grids both recover the imposed terminal torus homology (1,2,1), while their high-energy diagrams remain unconverged. All 36 effective-rotor problems retain material basis and grid sensitivity. Small finite-matrix residuals do not certify continuum accuracy. Protein closure counts retain every direction, including a minority nontrivial determinant in the ubiquitin control. Fifty-five implementation tests pass; release validation records state the executed scope and source hashes. Mathematical proofs and manuscript files are separate from this software/data archive.

Theorems require their written proofs; tests are implementation checks. The kernel is characteristic on descriptor laws, not necessarily on molecular configurations. Generic finite-support Fisher divergence is a limitation, not a rigidity score. Rank bounds concern unconstrained labelled shapes after proper rigid motion. Biological correlations are exploratory, with parent resampling and a fixed observed target mix; they are not target-conditioned predictive validation, causal evidence or clinical guidance.
